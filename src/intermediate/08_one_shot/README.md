# 08 · 单稳态触发器 one_shot

输入上升沿触发后，输出固定宽度（N 个时钟）的脉冲，期间不被重复触发。

## 这一课学什么
- 边沿触发 + 计数器 = 可控脉宽的单脉冲
- “不可重触发”：脉冲持续期间忽略新的触发沿
- 用途：脉冲展宽、复位脉冲、按键确认

> 软件类比：像带去抖/节流的事件处理——一次触发产生一段固定时长的“忙”状态，期间再来的事件被忽略（类似 debounce/throttle）。

## 运行
```bash
make        # 校验脉宽恰为 N 个时钟
make wave
make clean
```

## 上板玩法
- 把瞬时按键变成固定宽度脉冲去触发别的逻辑；或做上电复位脉冲展宽。

## 动手改
1. 改成**可重触发**版本（触发期间再来沿则重新计时）。
2. 脉宽参数化，外部可调。

## 对应真实开源项目
- 单稳态/脉冲展宽是定时逻辑常用件；对照本仓 `intermediate/19_prog_timer`、`20_watchdog`。
