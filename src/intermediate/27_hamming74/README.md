# 27 · 汉明码 (7,4) hamming74

4 位数据编码为 7 位码字，解码端用校验子定位并纠正任意单 bit 错误（SEC）。

## 这一课学什么
- 从“检错”到“纠错”的台阶：奇偶校验只能发现错，汉明码能**定位并纠正**单 bit 错
- 3 个校验位覆盖不同数据位组合，校验子（syndrome）的值=出错位置
- ECC 内存、存储纠错的入门原理

> 软件类比：像给数据加冗余校验，不仅能发现损坏、还能自动修复一处损坏——比 CRC 多了“纠正”能力（代价是更多冗余位）。

## 运行
```bash
make        # 16 个数据 × (无错 + 7 个单 bit 错) 全部验证
make wave
make clean
```

## 上板玩法
- 存储/传输的单 bit 纠错；扩展 SECDED 可再检出双 bit 错。

## 动手改
1. 扩成 (8,4) SECDED（加一个总校验位，纠 1 检 2）。
2. 故意注入双 bit 错，观察是否被误纠（理解 SEC 的局限）。

## 对应真实开源项目
- ECC 是 DDR/缓存的标配；原理见教科书纠错码章节，硬件思路对照本仓 `basics/13_parity`、`16_popcount`。
