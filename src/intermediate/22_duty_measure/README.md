# 22 · 占空比测量 duty_measure

测一个周期内的高电平时钟数与总周期时钟数，算出占空比百分比。

## 这一课学什么
- 同时计“高电平时长”和“整周期时长”，相除得占空比
- 周期边界用边沿检测划定
- 是 PWM 反馈/电源监测的基础测量

> 软件类比：像统计某状态在一个周期内“为真的时间比例”。硬件用两个计数器并行计时，周期结束时锁存比值。

## 运行
```bash
make        # 给定占空比的输入，校验测量值
make wave
make clean
```

## 上板玩法
- 监测电机/电源 PWM 实际占空比，做闭环反馈或故障检测。

## 动手改
1. 输出真正的百分比（需要除法，对照 `advanced/07_seq_divider`）。
2. 与 `intermediate/29_pwm_capture`（脉宽捕获）对照，理解“宽度 vs 占空比”。

## 对应真实开源项目
- PWM 反馈测量常见于电机/电源控制；对照本仓 `advanced/12_pwm_multi`、`intermediate/29_pwm_capture`。
