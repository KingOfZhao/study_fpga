# 04 · 按键消抖 + 边沿检测

机械按键/开关在按下与松开时会在几毫秒内**反复跳变**（抖动）。如果直接拿来当时钟使能或计数触发，会误触发很多次。本例给出工业上最常用的去抖 + 边沿检测电路。

## 这一课学什么
- **跨时钟域同步**：异步输入先过两级触发器（`sync0/sync1`），消除亚稳态
- **稳定计数**：电平要连续保持 `N` 个采样才认可，过滤掉短抖动
- **边沿检测**：在电平被认可改变的瞬间，输出**单周期脉冲** `btn_rise`/`btn_fall`
- 单周期脉冲是驱动"按一次走一步"逻辑（计数、翻页、状态跳转）的标准接口

> 软件类比：像给输入事件加**防抖（debounce）**，再把"电平"转成"事件"（rising/falling edge）——和前端按钮防抖一个道理，只是这里用硬件计数器实现。

## 运行
```bash
make            # 制造抖动→稳定，断言：恰好 1 次 rise、1 次 fall
make wave       # 看 btn_in 抖动而 btn_state 干净跳变、脉冲只出现 1 拍
make lint
make clean
```

## 上板玩法
- 把开发板按键接 `btn_in`，用 `btn_rise` 驱动一个计数器，做"按一次加一"的显示。
- `N` 取 `去抖时间 × 采样率`，例如 20ms × 1kHz = 20。

## 动手改
1. 增加一个"长按"检测：稳定高电平超过 M 拍后输出 `btn_long`。
2. 用上一课的分频器 `tick` 做采样使能，把采样率降到 1kHz 再去抖。
