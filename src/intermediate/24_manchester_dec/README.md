# 24 · 曼彻斯特解码器 manchester_dec

每 2 个 chip 还原 1 位数据，并校验两 chip 是否互补（检出编码错误）。

## 这一课学什么
- 解码 = 编码的逆：取每对 chip 的第一个作为数据位
- 合法性校验：两 chip 必须互补，否则是传输/编码错误
- 与 `23` 配对理解“自同步编码”全过程

> 软件类比：像反序列化时顺便做格式校验——既还原数据，又验证“每个符号格式合法”，不合法就报错。

## 运行
```bash
make        # 还原数据并校验合法性 + 错误检测
make wave
make clean
```

## 上板玩法
- 无时钟链路的接收端；实战需先做位同步/时钟恢复定位 chip 边界。

## 动手改
1. 加位同步（从首个跳变对齐 chip 边界）。
2. 接成完整链路验证（直接看 `projects/14_manchester_link`）。

## 对应真实开源项目
- 时钟恢复/曼彻斯特解码见以太网 PHY、RFID 阅读器；链路实战见本仓 `projects/14_manchester_link`。
