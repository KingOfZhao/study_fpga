# 28 · PS/2 接收器 ps2_rx

用系统时钟过采样 ps2_clk/ps2_data，在 ps2_clk 下降沿采样，解析 11 位帧并校验。

## 这一课学什么
- PS/2 帧：起始位 + 8 数据位 + 奇校验 + 停止位
- 设备提供时钟（ps2_clk），FPGA **过采样 + 检下降沿** 而非直接用它当时钟
- 奇校验错误检测

> 软件类比：像解析一个带起止位和校验位的串行协议帧——状态机逐位收集、最后校验合法性。难点在“别把外部时钟当时钟”。

## 运行
```bash
make        # tb 内置 PS/2 设备模型发送 0x1C，并验证校验错误检测
make wave
make clean
```

## 上板玩法
- 接 PS/2 键盘/鼠标读扫描码；ps2_clk/data 务必先过同步器。
