# 05 · 数码管显示 —— 二进制转 BCD + 扫描复用

要在数码管上显示一个数，需要两步：把二进制**转成十进制各位（BCD）**，再用**时分复用**把多位数码管轮流点亮。本例把两件事都做了。

## 这一课学什么
- **double dabble（移位加 3）**：一种纯组合就能把二进制转 BCD 的经典算法，无需除法器
- **BCD**：每 4 位表示一个十进制数字（0..9）
- **7 段译码**：数字 → 段码（共阳极低有效）
- **扫描显示 / 时分复用**：多位数码管共用段线，靠快速轮流 + 位选 `an` 制造"同时亮"的错觉（靠视觉暂留）

> 软件类比：`bin2bcd` 像 `sprintf("%d")` 把数字拆成各位；扫描显示像一个渲染循环每帧只画一位，循环够快肉眼就觉得整屏都在。

## 文件
| 文件 | 作用 |
|------|------|
| `bin2bcd.v` | 二进制→BCD（double dabble） |
| `seg7.v` | 数字→7 段段码 |
| `seven_seg.v` | 顶层：BCD + 扫描复用 + 位选 |

## 运行
```bash
make            # 穷举验证 bin2bcd(0..255) + seg7 段码表 + 扫描位选轮全
make wave       # 看 an 轮流"一冷"、seg 随之切换
make lint
make clean
```

## 上板玩法
- `SCAN_DIV` 设成"刷新率对应的分频值"（每位约 1~2ms 刷新一遍，整体 >60Hz 不闪）。
- 把上一课去抖后的计数值接到 `value`，做一个按键计数显示器。

## 动手改
1. 扩展到 4 位显示（加千位），`value` 改 16 位。
2. 给 `seg7` 增加十六进制 A~F 段码。
