# 01 · 有限状态机（FSM）—— 交通灯

FPGA 控制逻辑的核心套路：**有限状态机**。本例是经典的 Moore 型三段式 FSM。

## 这一课学什么
- **三段式 FSM 模板**（工业标准）：
  1. 状态寄存器（时序）：`state <= next_state`
  2. 次态逻辑（组合）：根据当前状态/输入算出 `next_state`
  3. 输出逻辑（组合）：Moore 型输出只取决于当前状态
- `localparam` 定义状态编码，可读性强
- **参数化时长**：`RED_TIME/GREEN_TIME/YELLOW_TIME`，仿真用小值、上板用大值
- testbench 里如何**对齐相位**并验证状态顺序与停留周期

> 软件类比：像一个 `enum State` + `switch`，但三段式把"状态转移"和"输出"拆成独立的组合电路，避免把所有逻辑塞进一个时钟块里——这对硬件可读性和时序收敛很关键。

## 仿真 vs 上板的时长
- 仿真：testbench 用 `RED=4/GREEN=3/YELLOW=2` 周期，几百纳秒跑完
- 上板：用默认 `50_000_000` 量级的计数（配合分频）才能得到"秒"级红绿灯

## 运行
```bash
make            # 验证 红->绿->黄 顺序与各相位周期数
make wave       # 观察 state/timer/light 的变化
make clean
```

## 踩坑提示（很重要）
testbench 在**时钟沿瞬间**读 `light` 会读到"旧值"（非阻塞赋值尚未生效）。
本例统一在 `@(posedge clk); #1;` 之后再采样，这是 RTL 验证的常见纪律。

## 动手改
1. 加一个行人按钮 `input req`，按下后缩短当前绿灯（变成 Mealy 输出）。
2. 用一个分频计数器把 100MHz 时钟变成 1Hz，驱动真实秒级红绿灯。
