# 09 · 边沿检测 edge_detector

两级寄存器打拍 + 比较，产生上升沿/下降沿/任意沿的**单拍**脉冲。

## 这一课学什么
- 记住“上一拍的值”：`q1` 是当前同步值、`q2` 是上一拍
- 上升沿 = `q1 & ~q2`，下降沿 = `~q1 & q2`
- 这两级寄存器同时也是异步输入的**同步器**（防亚稳态）——一举两得

> 软件类比：像比较“本次轮询值”和“上次值”来检测变化（`if (prev==0 && cur==1) onRisingEdge()`）。硬件里它是恒定运行的两个寄存器，每拍自动比较。

## 运行
```bash
make        # 校验上升/下降/任意沿各出 1 拍脉冲
make wave
make clean
```

## 上板玩法
- 把电平信号（按键、外部触发）转成单拍事件脉冲，喂给计数器/状态机。
