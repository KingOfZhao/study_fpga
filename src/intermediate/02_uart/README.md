# 02 · UART 收发器（含回环测试）

最实用的入门级通信外设：**UART**。本例实现发送器 `uart_tx` 与接收器 `uart_rx`，并用"回环"自校验。

## 协议（8N1）
```
空闲(1) | 起始位(0) | D0 D1 D2 D3 D4 D5 D6 D7 (LSB先) | 停止位(1) | 空闲(1)
```
- `CLKS_PER_BIT = 时钟频率 / 波特率`，例如 `100_000_000 / 115200 ≈ 868`
- 接收端在**位中点**采样，最稳；起始位先在中点确认再继续

## 这一课学什么
- 用 FSM 实现一个真实**串行协议**（START/DATA/STOP/CLEAN）
- **波特率计数器** `CLKS_PER_BIT`：硬件靠数时钟周期来"计时"
- **跨时钟域同步**：`rx_d1/rx_d2` 两级寄存器抗亚稳态
- 串/并转换：发送时并转串，接收时串转并（呼应 basics/04 移位寄存器）

> 软件类比：你写过的串口读写，底层就是这个状态机在数时钟、逐位拼字节。这里没有 OS 驱动，电路自己完成"采样—对齐—组装"。

## 运行
```bash
make            # TX 输出回接到 RX 输入，验证发什么收什么（0xA5/0x3C/0xFF/0x00）
make wave       # 观察 tx_serial 的起始/数据/停止位，以及 rx_dv 脉冲
make clean
```

## 验证踩坑（testbench 纪律）
- 发送前先等 `tx_active==0`，并**保持 `tx_dv` 直到 `tx_active` 拉高**，否则 1 拍的 `tx_dv` 脉冲可能恰好落在发送器的 `CLEAN` 周期被漏掉。
- 仿真用 `CLKS_PER_BIT=8` 加速；上板改回真实值。

## 动手改
1. 加奇偶校验位（8E1/8O1）。
2. 把 `rx_byte` 接到 7 段数码管或回环 echo 到 `tx`，做一个串口回显器。
3. 加 FIFO（见下一课）缓冲收发数据。
