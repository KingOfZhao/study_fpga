# 18 · 矩阵键盘扫描 keypad_scanner

4x4 矩阵键盘：逐行拉低、读列，定位按下的键并输出键码。

## 这一课学什么
- 矩阵扫描：16 个键只用 4 行 + 4 列共 8 根线（省引脚的经典手法）
- 逐行驱动 + 读回列状态 → 定位 (行,列) → 键码
- 实际还需消抖 + 防重键（本案例聚焦扫描定位）

> 软件类比：像二维遍历查表定位——一次激活一行、读取整列，逐行扫完即知哪个交点被按下。和数码管扫描是同一种“时分复用”思想的输入版。

## 运行
```bash
make        # tb 内置键盘模型，验证 4 个位置键码正确
make wave
make clean
```

## 上板玩法
- 接 4x4 薄膜键盘做数字输入；列输入务必经同步器（异步信号）。

## 动手改
1. 加消抖（对照 `intermediate/04_debounce`）和按下事件脉冲。
2. 把键码送数码管显示（对照 `projects/11_keypad_seg`）。
