# 21 · 频率计 freq_counter

在固定闸门窗口（GATE 个时钟）内统计输入信号上升沿数，换算出频率。

## 这一课学什么
- 测频法：已知闸门时间，数这段时间里来了多少个沿 → 频率
- 含输入**同步器 + 边沿检测**（异步信号必须先同步）
- 闸门越长越精确（但响应越慢）——精度/速度权衡

> 软件类比：像在固定 1 秒窗口里统计事件次数得到 QPS。差别是这里的“窗口”由硬件计数器精确划定，事件计数也是硬件完成。

## 运行
```bash
make        # 给定输入频率，校验闸门内计数正确
make wave
make clean
```

## 上板玩法
- 测量外部信号频率并上数码管/串口；低频信号宜用测周期法（数两个沿间的时钟）。

## 动手改
1. 低频时改测周期法，对比两种方法误差。
2. 频率值接数码管显示（直接看 `projects/06_freq_meter_seg`）。
