# 20 · 看门狗 watchdog

定时器在 TIMEOUT 内未被「喂狗」(kick) 则触发 `timeout`，用于死机保护。

## 这一课学什么
- 看门狗 = 倒计时器 + “喂狗清零”机制
- 正常时系统周期性 kick 重置计数；卡死后不再 kick → 超时报警/复位
- 安全关键系统的标配

> 软件类比：像一个必须被定期 `heartbeat()` 的健康检查——心跳停了就判定挂了并触发恢复动作。区别是它是独立硬件，主逻辑死了它照样运行。

## 运行
```bash
make        # 校验按时喂狗不超时、停止喂狗后准时 timeout
make wave
make clean
```

## 上板玩法
- 监控主状态机/软核，超时触发系统复位；TIMEOUT 用真实时间基准设定。

## 动手改
1. timeout 改成触发复位脉冲而非仅报警。
2. 加“喂狗窗口”（太早喂也算异常）。

## 对应真实开源项目
- 看门狗是 MCU/SoC 标准安全外设；可对照本仓 `intermediate/19_prog_timer` 理解其计时内核。
