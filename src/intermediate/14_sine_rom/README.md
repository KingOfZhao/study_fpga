# 14 · 正弦查找表 sine_rom

上电用 `$sin` 预计算一个周期的正弦表存进 ROM，地址扫描即得正弦波。

## 这一课学什么
- 用 `initial` + `$sin` 在仿真里生成查找表（上板时用 `.mem` 文件或 IP 初始化）
- 查表法：把昂贵的函数运算变成一次内存读取
- 可只存第一象限再用对称性折叠（省 3/4 存储）

> 软件类比：经典的“空间换时间”——预计算 `List.generate(N, (i)=>sin(...))` 缓存起来，运行时直接索引。硬件里这块表就是一个 ROM。

## 运行
```bash
make        # 校验 0/16/32/48 关键点与第一象限单调性
make wave
make clean
```

## 上板玩法
- DDS/信号发生器、音频合成、PWM 正弦调制的波形源。

## 动手改
1. 只存 1/4 周期，用对称性还原整周期。
2. 接相位累加器做 DDS（直接看 `advanced/05_dds`）。

## 对应真实开源项目
- 查表 + 相位累加是 DDS 核心；对照本仓 `advanced/05_dds` 与各家 NCO/DDS IP 文档。
