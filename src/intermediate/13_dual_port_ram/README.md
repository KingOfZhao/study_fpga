# 13 · 双口 RAM dual_port_ram

独立读端口 + 写端口（同一时钟），同步读出。映射到 FPGA 的 Block RAM。

## 这一课学什么
- FPGA 里的 RAM 不是“数组变量”，而是专门的 **Block RAM** 硬件资源
- 同步读：地址给出后**下一拍**才出数据（这点常坑新手）
- 双口：读写可同时进行，是帧缓冲/FIFO/查找表的存储基元

> 软件类比：像一个固定大小的 `List<int>`，但“读取”有一拍延迟、且读写端口物理独立。要让综合器识别成 Block RAM，得按特定模板写（否则会浪费成寄存器）。

## 运行
```bash
make        # 写入若干地址再读回校验，注意读延迟一拍
make wave
make clean
```

## 上板玩法
- 视频帧缓冲、音频采样缓冲、查找表、FIFO 的底层存储。

## 动手改
1. 改成真双口（两个读写端口）或不同读写位宽。
2. 用它搭一个简单 FIFO（加读写指针），对照同步 FIFO 案例。

## 对应真实开源项目
- Block RAM 推断模板见 Xilinx UG901 / Intel 的 RAM 推断指南；存储自检实战见本仓 `projects/12_sram_blockcopy`。
