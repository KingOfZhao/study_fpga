# 17 · 4 位数码管动态扫描 seven_seg_mux4

分时复用：用一组段线轮流点亮 4 个数位，靠视觉暂留显示 4 位数。

## 这一课学什么
- 为什么动态扫描：4 个数位共用 8 根段线，省大量引脚
- 轮流选通每个位（位选）+ 同步切换该位的段码
- 刷新率要足够高（>几十 Hz）才不闪烁；段/位选低有效（共阳）

> 软件类比：像单线程轮询刷新 4 个显示槽位——一次只更新一个，但刷新够快，人眼看起来 4 个同时亮。这就是“时分复用”。

## 运行
```bash
make        # 校验每个位选时段码与对应数字一致，且 4 位都被扫描到
make wave
make clean
```

## 上板玩法
- 直接驱动开发板 4 位数码管显示计数/时间；扫描时钟用 clock enable 产生。

## 动手改
1. 加小数点/消隐前导零。
2. 接 BCD 计数器/秒表显示真实数字（对照 `projects/07_stopwatch_seg`）。

## 对应真实开源项目
- 数码管动态扫描是开发板标配实验；参考 [fpga4fun](https://www.fpga4fun.com/) 与各开发板官方例程。
