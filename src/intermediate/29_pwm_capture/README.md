# 29 · 输入捕获 pwm_capture

测量输入脉冲的高电平宽度（时钟数），下降沿时输出结果。

## 这一课学什么
- 输入捕获：上升沿启动计数、下降沿锁存宽度
- 时间分辨率 = 时钟周期；宽度上限 = 计数器位宽
- 超声测距、遥控信号解码、PWM 反馈的基础

> 软件类比：像用高精度时间戳测一个事件持续了多久（`stop - start`）。硬件用一个计数器在脉冲期间自增，到下降沿读数。

## 运行
```bash
make        # 给定脉宽输入，校验捕获值
make wave
make clean
```

## 上板玩法
- HC-SR04 超声测距回波计时、航模遥控 PPM/PWM 解码。

## 动手改
1. 同时测高电平和周期，算占空比（对照 `intermediate/22_duty_measure`）。
2. 加溢出标志处理超长脉冲。

## 对应真实开源项目
- 输入捕获是 MCU 定时器标配功能；超声测距实验广见于各开发板教程。
