# 11 · 3:8 译码器 decoder3_8

3 位地址 → 8 位 one-hot 输出，带使能 `en`。`en=0` 时输出全 0。

## 这一课学什么
- 译码器 = “把二进制编号翻译成第 N 根线拉高”
- one-hot：任意时刻只有一位为 1，是片选/地址译码的基本形态
- 使能位是层级译码（大地址空间分块）的关键

> 软件类比：相当于 `1 << addr`（再与使能相与）。在硬件里这 8 根线常直接当**片选信号**：哪个外设被选中，就由地址译码这一步决定。

## 运行
```bash
make        # 校验 en=0 全零、en=1 时 one-hot 正确
make wave
make clean
```

## 上板玩法
- 用 3 个开关选 8 个 LED 之一点亮；或做存储器/外设的片选译码。

## 对应真实开源项目
- 地址译码是所有总线/存储系统的基础；参考 [HDLBits](https://hdlbits.01xz.net/) 及任意 SoC 的 memory map 译码逻辑。
