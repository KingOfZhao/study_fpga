# 09 · 1:4 解复用器 demux1_4

mux 的逆操作：按 `sel` 把一路数据分发到 4 路输出之一，其余输出清零。

## 这一课学什么
- 解复用 = “一进多出，按地址分发”
- **先给所有输出赋默认值（0）再 `case`**——这是避免锁存器的通用套路
- 与 `08_mux4_1` 配对：mux 收敛、demux 发散

> 软件类比：像把一个值写进数组的第 `sel` 个槽位、其余槽位保持 0：`out = List.filled(4,0)..[sel]=d`。硬件里 4 个输出是 4 根实际导线，同时被驱动。

## 运行
```bash
make        # 穷举 sel，校验只有选中路得到 d、其余为 0
make wave
make clean
```

## 上板玩法
- 用 `sel` 选择点亮 4 组外设之一（如 4 个数码管的位选），是动态扫描显示的雏形。

## 动手改
1. 加一个 `en` 使能：`en=0` 时全部输出 0。
2. 把它和 `08_mux4_1` 串起来（demux 再 mux），验证数据原样还原。
