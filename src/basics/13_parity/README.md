# 13 · 奇偶校验 parity

用归约异或 `^data` 一行算出校验位，是最简单的错误检测。

## 这一课学什么
- **归约运算符** `^`：把一个向量所有位异或到一起
- 偶校验位 = 数据所有位异或；奇校验再取反
- 一位翻转能被检出（但无法纠正、也测不出偶数位错）

> 软件类比：相当于 `data.toBitList().reduce((a,b)=>a^b)`。硬件里它综合成一棵异或树，深度 log(N)，一拍出结果。

## 运行
```bash
make        # 校验若干数据的奇/偶校验位
make wave
make clean
```

## 上板玩法
- UART 的奇偶校验位、存储器单 bit 检错都用它；可与 `intermediate/02_uart` 搭配。

## 动手改
1. 同时输出奇校验和偶校验两个位。
2. 升级到能**纠 1 位**的 `intermediate/27_hamming74`（汉明码），体会“检错→纠错”的台阶。
