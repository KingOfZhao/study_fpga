# 22 · BCD 计数器 bcd_counter

0→9 十进制循环计数，到 9 再 +1 时回 0 并输出进位脉冲 `carry`。

## 这一课学什么
- BCD（二-十进制）：用 4 位表示一个十进制数位（0–9）
- 到 9 回绕 + 进位脉冲 = 可级联成多位十进制计数
- 是数字钟、秒表、计数显示的基础

> 软件类比：像一个“逢十进一”的计数器，`carry` 就是进位信号。级联多个就相当于手算竖式里一位位往上进。

## 运行
```bash
make        # 校验 0..9 循环 + 第 10 拍进位脉冲
make wave
make clean
```

## 上板玩法
- 级联 2~6 个 BCD 计数器 + 数码管 = 数字钟/计数器显示。

## 动手改
1. 级联两位做 00–99 计数，验证十位进位。
2. 接 `intermediate/05_seven_seg` 直接显示十进制数。
