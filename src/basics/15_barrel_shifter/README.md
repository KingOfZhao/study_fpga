# 15 · 桶形移位器 barrel_shifter

单周期完成任意移位量的逻辑左/右移、循环移位、算术右移。

## 这一课学什么
- 桶形移位器：用多级 mux 在**一拍内**移动任意位数（不是一次移 1 位的串行移位）
- 逻辑右移补 0；算术右移 `>>>` 补符号位（需 `$signed`）；循环移位首尾相接
- 是 ALU、浮点对阶、定点定标的关键部件

> 软件类比：等价于 `x << n` / `x >> n` / `rotate(x,n)`。软件里一条指令搞定，硬件里它实际是一棵 log(N) 级的 mux 树——这就是“一条指令”底下的电路。

## 运行
```bash
make        # 校验各移位模式 + 移位量
make wave
make clean
```

## 上板玩法
- 作为 ALU 的移位单元；或做数据对齐/字节选择。

## 动手改
1. 增加“移位后空位填充值”可配置（补 0 / 补 1）。
2. 把它接进 `basics/05_alu`，给 ALU 增加移位指令。

## 对应真实开源项目
- 桶形移位器是所有 CPU ALU 的标配；参考 PicoRV32/VexRiscv 的移位实现，或教科书 Harris《DDCA》。
