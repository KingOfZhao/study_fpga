# 21 · 可逆计数器 updown_counter

带使能的加/减计数器：`up=1` 加、`up=0` 减，溢出/下溢自动回绕。

## 这一课学什么
- 时序逻辑里根据控制信号选择 `+1`/`-1`
- 使能 `en`：不使能时保持当前值（不是清零）
- 回绕行为（模 2^WIDTH）与软件无符号整数一致

> 软件类比：`if (en) cnt += up ? 1 : -1;`，且 `cnt` 是定宽无符号数会自然回绕。差别仍是“每个时钟沿才更新一次”。

## 运行
```bash
make        # 随机激励对照行为模型自校验
make wave
make clean
```

## 上板玩法
- 旋转编码器（`projects/01` 的 quad_decoder）输出方向 → 接 `up`，做计数旋钮。

## 动手改
1. 加 `load`/`clear` 同步控制端。
2. 接数码管显示当前计数（对照 `intermediate/05_seven_seg`）。
