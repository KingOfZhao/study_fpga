# 12 · 4 位比较器 comparator4

比较两个 4 位数，输出 `gt`/`eq`/`lt` 三个**互斥**标志（大于/等于/小于）。

## 这一课学什么
- 关系运算综合成组合比较网络
- “互斥 + 完备”：任意输入下三者恰有一个为 1（testbench 会验证这点）
- 比较器是排序、阈值判断、ALU 的 SLT 指令的基础

> 软件类比：就是 `a.compareTo(b)` 返回 -1/0/1 的硬件版本，只不过把三种结果摊成三根独立的线同时给出。

## 运行
```bash
make        # 穷举 256 组，校验 gt/eq/lt 恰有一个为 1
make wave
make clean
```

## 上板玩法
- 两组拨码当 `a`/`b`，三个 LED 看大于/等于/小于，做“数字比大小”小玩具。

## 动手改
1. 扩成 8 位/参数化位宽。
2. 只用 `eq` 和减法器的借位推出 `lt`/`gt`，理解比较与减法的关系（对照 `basics/05_alu`）。
