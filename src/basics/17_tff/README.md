# 17 · T 触发器 tff

“翻转”触发器：`t=1` 时每个时钟沿翻转，`t=0` 时保持。

## 这一课学什么
- 第一个**时序逻辑**单元：输出取决于历史状态 + 时钟沿
- `always @(posedge clk)` 里 `q <= ~q` 就是翻转
- T 触发器是分频器、计数器的基本细胞（接 `t=1` 就是 ÷2 分频）

> 软件类比：像一个带状态的对象，每次 `tick()` 在 `t` 为真时翻转字段。关键差别：它只在**时钟上升沿**这一瞬间更新，其余时间“冻结”。

## 运行
```bash
make        # 随机 t 序列对照行为模型
make wave
make clean
```

## 上板玩法
- `t` 接按键、`q` 接 LED，按一下灯翻转一次（注意按键要先消抖，见 `intermediate/04_debounce`）。

## 动手改
1. 串 4 个 T 触发器（每个 `t=1`）做 16 分频，观察波形频率逐级减半。
2. 用 T 触发器搭一个行波计数器，对照 `basics/01_counter`。

## 对应真实开源项目
- 触发器是所有时序电路的基石；[HDLBits](https://hdlbits.01xz.net/) 的 Sequential logic 章节有大量练习。
