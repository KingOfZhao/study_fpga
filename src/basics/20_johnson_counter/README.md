# 20 · 约翰逊计数器 johnson_counter

扭环计数器：把移位寄存器末位**取反**后反馈到首位，N 位产生 2N 个状态。

## 这一课学什么
- 与环形计数器的区别：反馈端取反 → 状态数翻倍（N 位得 2N 态）
- 相邻状态只差 1 位（类格雷码特性），译码无毛刺
- 常用于生成多相时钟、低毛刺分频

> 软件类比：还是循环移位，但进位规则变成“取反末位塞回开头”，于是序列长度从 N 变成 2N——一个小规则带来不同的状态空间。

## 运行
```bash
make        # 校验 2N 个状态按序循环
make wave
make clean
```

## 上板玩法
- 生成 4 相/6 相均匀相位信号；或做低毛刺的 LED 序列。

## 动手改
1. 对比同位宽下环形（`19`）与约翰逊计数器的波形与状态数。
2. 加非法状态自恢复逻辑。
