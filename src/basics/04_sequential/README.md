# 04 · 时序逻辑 —— 触发器与移位寄存器

时序逻辑 = 带"记忆"的电路。本课从最小存储单元 **D 触发器** 出发，组合成 **移位寄存器**。

## 这一课学什么
- **D 触发器**：FPGA 里一切寄存器/状态的最小单元，时钟边沿采样输入
- **同步复位** vs 异步复位（对比 01 课的异步复位）
- **移位寄存器**：N 个触发器串联，常用于串/并转换（UART、SPI 的底层就是它）
- 拼接运算 `{pout[N-2:0], sin}` 实现"左移一位、低位补 sin"

> 软件类比：触发器就像一个每个时钟周期才允许写一次的变量。`pout <= {pout[N-2:0], sin}` 不是数组操作，而是 8 个触发器同时把"左边邻居的值"拍进自己——全部并行发生在同一个时钟沿。

## 运行
```bash
make            # 串行喂入 8'b1011_0010，验证并行输出一致
make wave       # 观察 pout 如何每拍左移一位
make lint
make clean
```

## 动手改
1. 改成**并入串出**（PISO）：加 `load` 信号，一次性载入 8 位，然后逐位移出。
2. 把它接到 UART 发送器里（见 `intermediate/02_uart`）。
