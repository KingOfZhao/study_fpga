# 19 · 环形计数器 ring_counter

一个 1 在 N 位寄存器里循环移动（`1000→0100→0010→0001→1000`）。

## 这一课学什么
- 移位寄存器首尾相接 = 环形计数器
- 输出天生就是 **one-hot**，不需要额外译码
- 常用于顺序扫描、多相控制、状态轮转

> 软件类比：像一个循环右移的位掩码 `mask = rotateRight(mask, 1)`，始终只有一位为 1。它的“值”就是当前激活的相位。

## 运行
```bash
make        # 校验任意时刻恰有一个 1，且按序循环
make wave
make clean
```

## 上板玩法
- 直接驱动 N 个 LED 跑马灯；或做数码管/键盘的位选扫描时钟。

## 动手改
1. 加自启动逻辑：上电或异常落入全 0 时能自动恢复到合法 one-hot。
2. 改成 `20_johnson_counter`，对比状态数（环形 N 个 vs 约翰逊 2N 个）。
