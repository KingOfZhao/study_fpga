# 05 · ALU —— 算术逻辑单元（组合逻辑进阶）

把「全加器」扩展成一个**可选运算**的运算器：同一块组合电路，根据 `op` 选择加/减/与/或/异或/比较/移位。这是 CPU 数据通路的核心部件。

## 这一课学什么
- **多路选择 + 运算融合**：`case (op)` 在一个 `always @(*)` 里描述并行的候选运算，由 `op` 选一个输出
- **参数化位宽** `WIDTH`：同一份代码可综合成 4/8/16/32 位
- **进位/借位**：用 `{1'b0, a} + {1'b0, b}` 多留一位捕获 `carry`
- **避免锁存器**：组合 `always` 里给所有输出**先赋默认值**，否则会推断出 latch

> 软件类比：像一个 `switch(op)` 返回不同结果的纯函数。但这里 8 种运算的电路**同时存在**，`op` 只是选通哪一路输出——没有"跳转"，是多路选择器在选。

## 运算编码（op）
| op | 运算 | 说明 |
|----|------|------|
| 0 | ADD | a + b，带进位 |
| 1 | SUB | a − b，带借位 |
| 2 | AND | 按位与 |
| 3 | OR  | 按位或 |
| 4 | XOR | 按位异或 |
| 5 | SLT | a < b ? 1 : 0（无符号） |
| 6 | SHL | a 左移 b 位 |
| 7 | SHR | a 右移 b 位 |

## 运行
```bash
make            # 4 位宽，穷举 a/b × 8 种运算，全部断言通过则 [PASS]
make wave       # 观察 op 切换时 y 立即变化
make lint
make clean
```

## 在 Web 平台
这是**组合逻辑**，可用「🎛 交互式芯片仿真」拨动 `a`/`b`/`op` 开关，实时看 `y`/`zero`/`carry`。
