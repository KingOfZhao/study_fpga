# 08 · 4:1 多路选择器 mux4_1

参数化位宽的 4 选 1：用 2 位 `sel` 从 4 路输入里选一路输出。

## 这一课学什么
- `case(sel)` 是组合逻辑“选择”的标准写法
- **必须补 `default`**（或先赋默认值），否则综合器会推断出意料外的**锁存器**
- 参数化 `WIDTH`：一份代码适配任意位宽总线

> 软件类比：就是一个 `switch (sel)` 表达式，每个分支返回一路输入。区别是硬件里 4 路输入同时存在、同时被求值，`sel` 只是决定哪一路“接通”到输出。

## 运行
```bash
make        # 穷举 4 个 sel，自校验 [PASS]
make wave
make clean
```

## 上板玩法
- 4 组拨码当 4 路输入、2 个开关当 `sel`，LED 看被选中的那一路。

## 动手改
1. 扩成 **8:1**（`sel` 3 位），或用两级 4:1 拼出 8:1。
2. 反过来做 `09_demux1_4`（解复用），体会一对互逆操作。
