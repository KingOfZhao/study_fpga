# 24 · 通用移位寄存器 shift_register

支持并行装载 / 左移 / 右移 / 保持四种模式的通用移位寄存器。

## 这一课学什么
- 用 2 位 `mode` 选择四种操作（保持/左移/右移/装载）
- **串并转换**：移位寄存器是 SPI、UART、LED 串行驱动的核心
- 串行移入/移出 vs 并行装载/读出

> 软件类比：像一个固定长度的位队列，可以从一端塞入、整体平移、或一次性整体替换。它是“串行 ↔ 并行”这件事的硬件本体。

## 运行
```bash
make        # 随机激励对照模型，覆盖四种模式
make wave
make clean
```

## 上板玩法
- 驱动 74HC595 类串行 LED；或做 SPI/UART 的收发移位核心。

## 动手改
1. 用它实现一个 SPI 发送器（并行装载后逐位移出）。
2. 加“移位方向 + 串行输入位”做双向串并转换。

## 对应真实开源项目
- 串并转换是几乎所有串行协议的底层；实战见本仓 `intermediate/02_uart`、`advanced/02_spi_master`。
