# 02 · 组合逻辑 —— 全加器

用 `assign` 描述**纯组合逻辑**：输出只由当前输入决定，没有时钟、没有状态。

## 这一课学什么
- **组合逻辑** vs 时序逻辑：组合逻辑 = 一坨门电路，输入变输出立刻变（受门延迟影响）
- **连续赋值** `assign` 与 `wire`
- 逻辑运算符：异或 `^`、与 `&`、或 `|`
- 全加器真值表：`{cout,sum} = a + b + cin`

> 软件类比：`assign sum = a ^ b ^ cin;` 不是"执行一次赋值"，而是一条**永远成立的连线**——只要 a/b/cin 变，sum 立刻跟着变，像电子表格里的公式而非命令式语句。

## 运行
```bash
make            # 穷举 8 种输入，全部断言通过则打印 [PASS]
make wave       # 观察输入翻转时输出如何立即变化
make lint
make clean
```

## 波形里看什么
输入 `{a,b,cin}` 每 5ns 走一个组合（000→111），`sum`/`cout` 随之变化，无时钟参与。

## 动手改
1. 用 4 个 `full_adder` 例化，串成一个 4 位**行波进位加法器**（ripple-carry adder）。
2. 思考：为什么链越长，组合逻辑延迟越大？这就是后面要学的"时序收敛"的根源。
