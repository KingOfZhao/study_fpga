# 18 · JK 触发器 jkff

“万能”触发器：`00` 保持 / `01` 清 0 / `10` 置 1 / `11` 翻转。

## 这一课学什么
- 一种触发器涵盖 D/T/SR 的全部行为（用 J、K 两个控制位编码 4 种动作）
- 时序逻辑里用 `case({j,k})` 描述次态
- 历史上 JK 触发器是教学经典，理解“控制位 → 次态”的映射

> 软件类比：像一个状态机字段，根据 `(j,k)` 这对“命令”决定下一拍是保持、清零、置位还是翻转——一个二维查表。

## 运行
```bash
make        # 随机 JK 序列对照模型自校验
make wave
make clean
```

## 上板玩法
- 两个开关当 J/K、LED 看 Q，手动体验四种行为。

## 动手改
1. 把 JK 退化成 T（`j=k=t`）和 D（`j=d, k=~d`），验证等价。
2. 用 JK 触发器搭一个简单计数器。

## 对应真实开源项目
