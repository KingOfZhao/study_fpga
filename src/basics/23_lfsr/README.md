# 23 · 线性反馈移位寄存器 lfsr

用本原多项式做反馈的移位寄存器，产生最大长度伪随机序列。

## 这一课学什么
- LFSR：抽头位异或后反馈移位，本原多项式 `x^8+x^6+x^5+x^4+1`
- 8 位最大长度序列周期 = 255（遍历除全 0 外所有状态）
- 全 0 是“死状态”，必须避开（初值非 0）

> 软件类比：像一个极轻量的伪随机数生成器（PRNG）——一次移位 + 几个异或就出下一个数。但它是确定性的、可复现的，适合做测试图样/扰码。

## 运行
```bash
make        # 校验 255 拍回到初值且全程无全 0 态
make wave
make clean
```

## 上板玩法
- 伪随机数、数据扰码、内建自测试(BIST)图样、噪声/抖动发生。

## 动手改
1. 换不同抽头，观察是否仍是最大长度（非本原多项式周期会变短）。
2. 扩到 16/32 位，做更长周期的伪随机源。

## 对应真实开源项目
- LFSR 是 CRC、扰码、PRBS 的共同基础；可对照本仓 `intermediate/25_crc8`、`26_crc16`。
