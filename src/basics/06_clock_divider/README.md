# 06 · 分频器 / 节拍发生器（时序逻辑进阶）

FPGA 里通常只有一个高频时钟（如 50/100MHz），但很多任务需要"慢节拍"。**不要去造新时钟**，而是用计数器在快时钟下产生一个**单周期使能脉冲 `tick`**，让后续逻辑"每 DIV 拍动一次"。

## 这一课学什么
- **分频 = 计数 + 比较**：计满 `DIV-1` 就回零并拉高 `tick` 一拍
- **使能脉冲 vs 衍生时钟**：用 `tick` 做时钟使能（`if (tick) ...`）比生成新时钟更安全（避免时钟域问题）
- `$clog2()` 自动算计数器位宽，随参数 `DIV` 变化
- 同步设计：所有寄存器只在同一个 `clk` 边沿更新

> 软件类比：`if (++i % DIV == 0) doSlowThing();`——但这里是纯硬件计数器，`tick` 就是那个 `% DIV == 0` 的瞬间。

## 运行
```bash
make            # DIV=5：验证相邻 tick 间隔恒为 5 个时钟
make wave       # 观察 cnt 循环 0..4、tick 每 5 拍高 1 拍
make lint
make clean
```

## 上板玩法
- 把 `DIV` 设成 `时钟频率`（如 50_000_000），`tick` 就是 **1Hz**，驱动 LED 每秒闪一次。
- 多级分频：用一个慢 `tick` 再驱动另一个计数器，得到秒/分。

## 动手改
1. 增加 `output reg clk_out`，在每次 `tick` 时翻转，得到占空比 50% 的分频时钟（频率减半于 tick）。
2. 让 `DIV` 改为运行时可配置（加一个 `input [N-1:0] div_val`）。
