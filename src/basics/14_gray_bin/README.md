# 14 · 格雷码互转 gray_bin

二进制 ↔ 格雷码双向转换。格雷码的特点：相邻两个数只差 **1 个 bit**。

## 这一课学什么
- `bin→gray = b ^ (b>>1)`（一行组合逻辑）
- `gray→bin` 用前缀异或链
- 为什么重要：跨时钟域传递计数器时，多位同时变化会采到中间乱码；格雷码每次只变 1 位，避免这种风险

> 软件类比：像一种特殊的整数编码方案，`encode/decode` 是一对互逆纯函数。它的价值不在算法本身，而在**物理时序**——这是软件里没有的考量。

## 运行
```bash
make        # 校验往返一致 + 相邻值仅 1 位变化
make wave
make clean
```

## 上板玩法
- 旋转编码器的机械码盘常用格雷码；异步 FIFO 的读写指针必须用它。

## 动手改
1. 参数化位宽，验证任意位宽下“相邻仅 1 位变化”仍成立。
2. 直接去看 `intermediate/12_async_fifo` 里格雷码指针的实战用法。

## 对应真实开源项目
- 异步 FIFO 的格雷码指针是工业标准做法；经典参考 Cliff Cummings 的 async FIFO 论文，实战见本仓 `intermediate/12_async_fifo`。
