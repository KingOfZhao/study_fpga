# 03 · MUX 与译码器

两个最常用的组合逻辑积木：**多路选择器**（从多路数据里选一路）和**译码器**（把二进制编码展开成 one-hot）。

## 这一课学什么
- `always @(*)` + `case` 描述组合逻辑（区别于上一课的 `assign`）
- **参数化设计** `#(parameter WIDTH=4)`：一份代码生成不同位宽的电路（类似泛型）
- **锁存器陷阱**：组合 `always` 里若某分支没给输出赋值，综合器会推断出意料之外的锁存器——所以每个分支、`default` 都要赋值
- one-hot 编码：`4'b0001 << a`

> 软件类比：MUX 像 `switch(sel)` 返回不同变量，但它是**并行存在的硬件**——四路数据同时送到选择器，`sel` 只是决定哪一路接通输出。

## 运行
```bash
make            # [PASS] 表示 MUX 4 种选择 + 译码器 5 种情况全部正确
make wave
make lint
make clean
```
