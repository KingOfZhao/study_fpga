# 20 · 带行人请求的红绿灯 traffic_pedestrian

`debounce + 交通灯 FSM`：行人按钮去抖后登记请求，主路绿灯安全提前结束放行行人。

## 这一课学什么
- 带外部事件输入的状态机（比纯定时交通灯进了一步）
- 请求被“记住”直到安全切换时机才响应（不能立刻打断当前相位）
- 按钮先去抖，避免误触发

> 软件类比：像一个带事件标志的状态机——按钮请求先置标志，主循环在合适的状态转换点才消费它，保证状态转换安全有序。

## 运行
```bash
make        # 注入带抖动的行人请求，校验状态序列与时序安全
make wave
make clean
```

## 上板玩法
- 路口红绿灯 + 行人按钮：按钮按下后绿灯安全结束、放行行人。

## 动手改
1. 加行人倒计时显示（接数码管）。
2. 加夜间黄灯闪烁模式。
