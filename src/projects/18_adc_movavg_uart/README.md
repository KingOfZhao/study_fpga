# 18 · 采样滤波串口上报 adc_movavg_uart

`fir_movavg + uart_tx`：输入样本经 N 点移动平均滤波后，通过 UART 上报。

## 这一课学什么
- 数据流水线：采集 → 滤波(降噪) → 上报
- 移动平均 = 最简单的低通滤波（窗口越大越平滑、响应越慢）
- 把处理结果经串口输出给上位机

> 软件类比：像对一串读数做滑动窗口求平均再上报——平滑掉抖动只保留趋势。窗口大小就是平滑强度（延迟与平滑的权衡）。

## 运行
```bash
make        # 给带噪样本，校验滤波输出并经串口上报
make wave
make clean
```

## 上板玩法
- ADC 采样读数降噪后上报上位机绘图；窗口大小权衡平滑度与延迟。

## 动手改
1. 换成指数加权移动平均(EWMA)，省存储。
2. 升级成真正的 FIR（对照 `advanced/04_fir`）。

## 对应真实开源项目
- 移动平均/FIR 是 DSP 入门；FIR 内核见本仓 `advanced/04_fir`、`advanced/10_mac`，串口见 `intermediate/02_uart`。
