# 15 · 带 CRC 的 UART 帧 uart_crc_frame

发送端组帧(数据 + CRC)，接收端收帧并校验 CRC，检出传输错误。

## 这一课学什么
- 真实协议帧 = 数据 + 校验（而非裸字节流）
- 发送端边发边算 CRC 附在帧尾；接收端边收边算并比对
- 组合 UART(`02`) + CRC(`intermediate/25`) 的协议级设计

> 软件类比：像给网络包加校验和——发送时计算附上，接收时重算比对，不一致就丢弃。这是可靠通信的基本盘。

## 运行
```bash
make        # 发正确帧校验通过；注入错误校验失败
make wave
make clean
```

## 上板玩法
- 串口可靠传输：抗干扰，检出线路误码并请求重传。

## 动手改
1. 加帧头/长度字段，做成完整帧格式。
2. 加 ACK/重传（最简单的可靠传输协议）。

## 对应真实开源项目
- 带 CRC 的串口帧是 Modbus-RTU 等协议的核心；CRC 内核见本仓 `intermediate/26_crc16`，串口见 `intermediate/02_uart`。
