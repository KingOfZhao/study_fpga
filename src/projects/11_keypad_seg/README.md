# 11 · 矩阵键盘+数码管 keypad_seg

`keypad_scanner + seg7`：按下的键码实时显示在数码管上。

## 这一课学什么
- 输入(键盘扫描) → 显示(数码管) 的完整人机交互链路
- 键码到段码的映射（查表）
- 两个“时分复用”模块（键盘扫描 + 数码管扫描）协同工作

> 软件类比：像“键盘输入 → 更新显示”的最小交互循环。扫描相当于轮询输入设备，段码映射相当于渲染字符。

## 运行
```bash
make        # 模拟按下若干键，校验数码管显示对应键码
make wave
make clean
```

## 上板玩法
- 4x4 键盘输入数字并显示，做计算器/密码输入的前端。

## 动手改
1. 支持多位输入（移位拼成多位数）。
2. 加按键去抖与重复输入抑制。

## 对应真实开源项目
- 键盘 + 显示是经典综合实验；模块见本仓 `intermediate/18_keypad_scanner`、`intermediate/05_seven_seg`。
