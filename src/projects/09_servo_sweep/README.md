# 09 · 舵机自动扫摆 servo_sweep

`位置斜坡发生器 + servo_pwm`：舵机角度在两端之间自动来回扫动。

## 这一课学什么
- 用一个来回计数的斜坡发生器自动产生位置序列
- 接舵机 PWM 把位置变成脉宽
- 到端点反向（三角波形状的位置轨迹）

> 软件类比：像一个动画补间——位置值在 [min,max] 间线性往返，每帧更新一次，再映射到舵机角度。

## 运行
```bash
make        # 校验位置斜坡来回 + 对应脉宽
make wave
make clean
```

## 上板玩法
- 舵机自动来回扫（云台/雷达扫描效果）；调斜坡速率改扫动快慢。

## 动手改
1. 改成正弦轨迹（更平滑，接 `intermediate/14_sine_rom`）。
2. 多舵机不同相位扫摆。

## 对应真实开源项目
- 舵机控制见各机器人项目；舵机 PWM 内核见本仓 `advanced/13_servo_pwm`。
