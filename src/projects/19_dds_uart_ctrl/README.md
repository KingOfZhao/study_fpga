# 19 · 串口控频 DDS dds_uart_ctrl

`uart_rx + DDS`：串口接收频率字，实时改变 DDS 输出频率。

## 这一课学什么
- 串口配置 + 信号生成的组合：上位机发命令，硬件改输出
- 收到的字节写入 DDS 的频率寄存器 `fword`
- “可远程配置的信号源”雏形

> 软件类比：像一个接收配置命令的服务——收到“设频率=X”就更新内部参数，输出随之改变。串口是命令通道，DDS 是被控对象。

## 运行
```bash
make        # 串口发若干频率字，校验 DDS 输出频率随之变化
make wave
make clean
```

## 上板玩法
- 电脑串口实时调节 FPGA 输出的正弦/方波频率（简易信号发生器）。

## 动手改
1. 加多字节命令解析（频率/幅度/波形选择）。
2. 加波形选择（正弦/方波/三角）。

## 对应真实开源项目
- 串口控制 + DDS 是 SDR/信号源常见组合；DDS 内核见本仓 `advanced/05_dds`，串口见 `intermediate/02_uart`。
