# 05 · 按键计数串口上报 button_uart_report

`debounce + 计数器 + uart_tx`：每次去抖按下计数 +1 并经 UART 上报新值。

## 这一课学什么
- 一条完整链路：物理输入(按键) → 清洗(消抖) → 处理(计数) → 输出(串口)
- 把“按下事件”可靠地转成一次计数（消抖 + 边沿）
- 事件触发的数据上报模式

> 软件类比：像“点击事件 → 更新计数 → 上报后端”的前端逻辑。消抖相当于防抖动的事件处理，串口相当于网络上报。

## 运行
```bash
make        # 模拟多次带抖动按下，校验串口上报的计数值
make wave
make clean
```

## 上板玩法
- 按键计数器，每按一次电脑串口助手收到一个新计数值。

## 动手改
1. 上报改成多字节（如“CNT=12\n”可读文本）。
2. 加长按清零。

## 对应真实开源项目
- 消抖 + 上报是典型上板组合；消抖参考 [fpga4fun Debouncer](https://www.fpga4fun.com/Debouncer.html)，串口参考 nandland。
