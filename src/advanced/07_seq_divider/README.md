# 07 · 序列除法器 seq_divider

移位-相减无符号除法，W 拍输出商与余数。

## 这一课学什么
- FPGA 没有“除法指令”，除法要么用 IP、要么自己迭代实现
- 恢复余数法：每拍试减、够减则商位=1，逐位求商
- **多周期**算法：用 valid/done 握手，W 位除法要 W 拍

> 软件类比：就是小学竖式长除法的硬件版——逐位试商。软件 `a ~/ b` 一行的背后，硬件得花 W 拍迭代（或砸很多资源做并行）。

## 运行
```bash
make        # 随机被除数/除数，对照校验商与余数
make wave
make clean
```

## 上板玩法
- 需要除法但要省资源时；或除数运行时可变无法用移位代替时。
