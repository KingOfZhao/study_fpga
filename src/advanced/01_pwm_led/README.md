# 01 · PWM 脉宽调制（LED 呼吸灯 / 电机调速）

用一个自由运行计数器 + 比较器生成 PWM 信号——FPGA 控制模拟外设的标准手法。

## 这一课学什么
- **自由运行计数器**回绕产生固定周期
- **比较器**：`pwm_out = (cnt < duty)`，改 `duty` 即改占空比
- 占空比分辨率 = `2^WIDTH`（位宽决定调节精度）

> 软件类比：像在一个固定频率的循环里按比例输出高/低。但这里是纯硬件，输出抖动极小、频率可以非常高——这正是 FPGA 适合做实时控制的原因。

## 运行
```bash
make            # 验证 duty=0/4/8/12/15 时一个周期内高电平拍数
make wave       # 观察不同 duty 下 pwm_out 占空比
make clean
```

## 上板玩法
- 用一个慢计数器周期性改变 `duty`，做 **LED 呼吸灯**。
- 提高时钟/位宽用于电机或舵机（注意舵机需要特定频率，约 50Hz）。
