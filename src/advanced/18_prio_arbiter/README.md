# 18 · 固定优先级仲裁器 prio_arbiter

组合电路，最低索引优先，输出单热(one-hot) grant。

## 这一课学什么
- 固定优先级：多个请求同时来时，编号最小的赢
- 经典写法 `grant = req & (~req + 1)`（取最低置位）或优先级链
- 简单、低延迟，但高优先方持续请求会饿死低优先方

> 软件类比：像 `requests.firstWhere((r)=>r)` 的“返回第一个就绪项”。纯组合逻辑，一拍出 grant。

## 运行
```bash
make        # 穷举 256 种请求组合校验 one-hot grant
make wave
make clean
```

## 上板玩法
- 中断优先级、资源争用判优；对公平性无要求且看重延迟的场合。

## 动手改
1. 改成可配置优先级顺序。
2. 换成轮询消除饿死（对照 `advanced/17_rr_arbiter`）。

## 对应真实开源项目
- 优先级判优是中断控制器/总线的基础；对照 RISC-V PLIC、各 SoC 中断控制器。
