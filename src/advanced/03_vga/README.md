# 03 · VGA 时序产生器（640×480@60Hz）

VGA 显示靠两个计数器：一个数像素（行内），一个数行（场内）。在特定区间拉出 **hsync/vsync** 同步脉冲，可见区里把像素坐标 `(px, py)` 送给画图逻辑。掌握它就能让 FPGA 直接驱动显示器。

## 这一课学什么
- **行/场双计数器**：`hcnt` 计满一行进 `vcnt`，`vcnt` 计满一帧归零
- **时序段**：可见区 → 前肩(front porch) → 同步(sync) → 后肩(back porch)，缺一不可
- **同步极性**：640×480 的 hsync/vsync 都是**负极性**（同步段拉低）
- **像素坐标**：`active` 为高时 `(px, py)` 有效，画图逻辑据此决定每个像素颜色
- 全参数化：换一组参数（来自标准时序表）即可支持 800×600、1024×768 等

> 软件类比：像一个固定节奏的双重循环 `for y: for x:`，但它**永不停**、由硬件时钟驱动，每个像素时刻坐标都"自动"前进，你只需根据 `(x,y)` 输出颜色。

## 关键时序（默认参数）
| 方向 | 可见 | 前肩 | 同步 | 后肩 | 总计 |
|------|------|------|------|------|------|
| 水平 | 640 | 16 | 96 | 48 | **800** |
| 垂直 | 480 | 10 | 2 | 33 | **525** |

像素时钟约 **25.175MHz**（仿真里用任意 `clk` 即可）。

## 运行
```bash
make            # 小参数实例快速验证时序逻辑 + 默认实例验证 hsync 宽度=96
make wave       # 看 hcnt/vcnt 计数、hsync/vsync 脉冲、active 区间
make lint
make clean
```
> 说明：testbench 用一组**小参数**实例快速跑 2 整帧做性质验证（可见像素数、脉冲宽度/个数、坐标范围），并另用**默认 640×480** 实例确认真实 `hsync` 宽度为 96，兼顾正确性与仿真速度。

## 上板玩法
- 接 VGA 接口的 3 路电阻 DAC，`active` 时根据 `(px,py)` 输出 RGB，先画彩条/棋盘格。
- 用 `py` 高位做渐变、用 `(px^py)` 做花纹。

## 动手改
1. 画一个移动的方块（用上一课的分频器做慢速移动）。
2. 改参数支持 800×600@60，对照标准时序表填表即可。
