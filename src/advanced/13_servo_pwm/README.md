# 13 · 舵机 PWM servo_pwm

RC 舵机控制：固定 ~20ms 周期，高电平宽度随 `pos` 在 1~2ms 间线性变化。

## 这一课学什么
- 舵机不是看占空比、而是看**高电平绝对宽度**（1ms→0°，2ms→180°）
- 周期固定 ~50Hz，脉宽 = 基准宽度 + pos 映射的增量
- 与普通 PWM 的关键区别：关注脉宽而非比例

> 软件类比：像把一个角度值映射到一个脉宽（`map(pos, 0..255, 1ms..2ms)`），周期性输出。注意这里时间是“绝对值”，不能像调光那样只看比例。

## 运行
```bash
make        # 校验 pos 端点/中点对应的脉宽
make wave
make clean
```

## 上板玩法
- 驱动 SG90 等 RC 舵机（注意舵机供电与 FPGA 分开、共地）。

## 动手改
