# 12 · 多通道 PWM pwm_multi

共享一个计数器、N 路独立占空比阈值，一套时基驱动多路 PWM。

## 这一课学什么
- 资源复用：N 路 PWM 共用一个自由计数器，各自只比较自己的阈值
- 所有通道相位对齐（同一计数器）
- 用 `generate` 批量例化比较器

> 软件类比：像一个主循环里同时维护多个“占空比变量”，每个独立比较输出。共享时基保证它们严格同步。

## 运行
```bash
make        # 校验各通道在各自 duty 下的高电平拍数
make wave
make clean
```

## 上板玩法
- 多路 LED 调光、RGB 混色（见 `projects/08_pwm_rgb`）、多电机/多舵机驱动。

## 动手改
1. 每路加独立相位偏移（错峰，降低电源瞬时电流）。
2. duty 接慢扫描做多路呼吸灯。

## 对应真实开源项目
- 多路 PWM 见各电机驱动/LED 控制器 IP；RGB 混色实战见本仓 `projects/08_pwm_rgb`。
