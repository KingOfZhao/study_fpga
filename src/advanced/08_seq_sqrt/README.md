# 08 · 整数平方根 seq_sqrt

逐位逼近开方，W/2 拍输出 `floor(sqrt(n))`，仅用加减移位。

## 这一课学什么
- 非恢复式逐位开方：每次试一个候选位，比较平方是否超过 n
- 只用加减和移位，无乘法/无除法
- 又一个**多周期迭代**算法的范例

> 软件类比：像二分/逐位逼近求 `sqrt(n).floor()`。软件调库一行，硬件把它拆成 W/2 步可综合的整数运算。

## 运行
```bash
make        # 随机 n 对照 floor(sqrt(n)) 校验
make wave
make clean
```

## 上板玩法
- 向量模长、RMS、距离计算里的开方步骤。

## 动手改
1. 同时输出余数（n - root²）。
2. 扩展定点小数开方。
