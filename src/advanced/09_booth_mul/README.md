# 09 · Booth 有符号乘法器 booth_mul

Booth 基-2 算法，W 拍算出 2W 位有符号乘积。

## 这一课学什么
- Booth 算法：扫描乘数相邻位，把连续的 1 串转成“加/减/不动”，统一处理符号
- 有符号乘法不用特判正负——Booth 编码天然正确
- 又一个移位 + 加减的迭代算术范例

> 软件类比：像优化版的“逐位乘加”，通过编码减少加法次数并自动处理符号。软件 `a * b` 一条指令，这里展示它在没有硬乘法器时怎么实现。

## 运行
```bash
make        # 含随机用例对照校验 2W 位有符号乘积
make wave
make clean
```

## 上板玩法
- 无 DSP 器件上的有符号乘法；理解 CPU 乘法器内部原理。

## 动手改
1. 改成基-4 Booth（每拍处理 2 位，减半周期）。
2. 对比直接用 `*`（综合成 DSP）的资源/速度差异。

## 对应真实开源项目
- Booth 乘法器是计算机算术教科书经典；硬乘法器对照 Xilinx DSP48、各 RISC-V 核乘法单元。
