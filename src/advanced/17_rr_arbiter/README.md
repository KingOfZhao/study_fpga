# 17 · 轮询仲裁器 rr_arbiter

Round-Robin 仲裁：N 路请求公平轮转授权，避免某一路饿死。

## 这一课学什么
- 固定优先级会饿死低优先方；轮询用一个“起点指针”循环移动保证公平
- 每次授权后指针移到被授权者之后，下次从那里开始找
- 总线/端口共享访问的标准仲裁策略

> 软件类比：像多个任务公平轮流拿锁/时间片（round-robin 调度），而不是高优先级永远抢先。

## 运行
```bash
make        # 多路持续请求，校验授权公平轮转
make wave
make clean
```

## 上板玩法
- 多主设备共享总线、多端口写同一 FIFO/存储的访问仲裁。

## 动手改
1. 加权轮询（某些路分到更多机会）。
2. 与 `advanced/18_prio_arbiter` 对比公平性与延迟。

## 对应真实开源项目
- RR 仲裁广见于 NoC/总线互连；参考各 AXI 互连 IP 与开源 SoC 的总线仲裁器。
