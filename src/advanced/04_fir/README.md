# 04 · 移动平均 / FIR 滤波器

数字信号处理（DSP）在 FPGA 上的入门：**移动平均**是最简单的 FIR（有限冲激响应）滤波器，用来平滑信号、抑制噪声。本例用"运行和 + 滑动窗口"做高效实现。

## 这一课学什么
- **滑动窗口**：用移位寄存器保存最近 N 个样本
- **运行和（running sum）**：`新和 = 旧和 + 新样本 − 最旧样本`，避免每拍重复累加 N 项
- **定点除法优化**：N 取 2 的幂时，除以 N = 右移，零成本
- **流水线 + valid 握手**：`valid_in`/`valid_out` 标记数据有效，延迟 1 拍
- **位宽规划**：运行和要留 `log2(N)` 额外位防溢出

> 软件类比：就是一个固定长度的环形缓冲 + 求和取平均。但硬件里它**每个时钟处理一个样本**、吞吐率恒定，这正是 FPGA 做实时 DSP 的优势。

## 运行
```bash
make            # 喂一串样本，用参考模型逐拍比对移动平均结果
make wave       # 看 x 突变时 y 被平滑、阶跃响应是斜坡
make lint
make clean
```

## 进阶：一般 FIR
把"全部系数 = 1/N"换成任意系数 `h[k]`，即 `y[n] = Σ h[k]·x[n−k]`，就是通用 FIR（低通/高通/带通由系数决定）。乘法用 FPGA 的 DSP 硬核完成。

## 动手改
1. 改成带系数的 4 抽头 FIR（如 `[1,3,3,1]/8`），观察频率响应变化。
2. 把 N 改成 8/16，对比平滑程度与延迟（窗口越长越平滑但越滞后）。
