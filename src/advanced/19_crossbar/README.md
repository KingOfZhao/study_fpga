# 19 · 交叉开关 crossbar

NxN 全连接交叉开关：每个输出口由 `sel` 选择任一输入。

## 这一课学什么
- crossbar = N 个独立的 N:1 mux（每个输出各选一路输入）
- 任意输入到任意输出的全连接路由
- 是片上互连(NoC)、多端口存储、交换芯片的基础

> 软件类比：像一张路由表，把每个输出端口映射到某个输入端口。N 个输出各有一张“选择器”，互不影响。

## 运行
```bash
make        # 随机 sel 组合，校验每个输出等于所选输入
make wave
make clean
```

## 上板玩法
- 多主多从总线互连、数据流路由、信号矩阵切换。

## 动手改
1. 加输出仲裁，处理“多输出抢同一输入”的带宽。
2. 规模增大时观察资源随 N² 增长（理解 crossbar 的成本）。

## 对应真实开源项目
- crossbar 是 NoC/交换结构核心；参考 Xilinx AXI Crossbar IP 文档与各开源 NoC 项目。
