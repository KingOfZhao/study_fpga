# 给软件工程师的 FPGA 思维迁移指南

你有 7 年软件（Dart）经验，这是巨大优势，但也有几个**反直觉**的坎。本文用你熟悉的概念帮你跨过去。

## 1. 最大的不同：并行 vs 串行

```dart
// Dart：自上而下，一条条执行
a = 1;
b = a + 1;   // b 一定看到 a=1
c = b + 1;
```

```verilog
// Verilog：下面三个 always/assign 块是三块独立电路，永远同时工作
assign x = a & b;        // 一直在算
always @(posedge clk) y <= x;   // 每个时钟沿同时更新
always @(posedge clk) z <= y;
```

**没有"先后"，只有"同时"。** 代码的书写顺序不代表执行顺序（组合逻辑除外，靠数据依赖）。

## 2. 不是变量，是导线和触发器

| 软件概念 | 硬件对应 | 关键差异 |
|----------|----------|----------|
| 局部变量 | `wire`（导线） | 没有存储，值随驱动源实时变化 |
| 字段/状态 | `reg` + 时钟（触发器） | 只能在时钟沿改变，消耗物理触发器资源 |
| `final`/常量 | `parameter`/`localparam` | 编译期固定，可用于生成不同规模电路 |
| 函数调用 | 模块例化 `module`（实例化） | 是**复制一份硬件**，不是跳转执行 |
| `for` 循环 | 综合时**展开**成 N 份硬件 | 不是运行时迭代！循环次数必须编译期可知 |
| 数组 | 寄存器组 / 片上 RAM | 多端口访问受限（不能随便并发读写任意多个） |

> 记住：写一个 `for (i=0;i<8;i=i+1)` 不是"循环 8 次"，而是"造 8 套电路并排放好"。

## 3. `=` vs `<=`（阻塞 vs 非阻塞）—— 新手头号杀手

```verilog
// 组合逻辑用阻塞 =（像普通顺序赋值）
always @(*) begin
    t = a + b;
    y = t + c;     // y 立刻看到新 t
end

// 时序逻辑用非阻塞 <=（所有右边先算好，再同时更新左边）
always @(posedge clk) begin
    a <= b;
    b <= a;        // 实现交换！因为右边用的是"旧值"
end
```

软件类比：非阻塞 `<=` 像"先快照所有右值，再统一提交"——类似数据库事务里读到的是事务开始时的快照。
**规则：时序块用 `<=`，组合块用 `=`，不要混用。**

## 4. 时钟和复位是一等公民

软件里没有"全局心跳"，FPGA 里几乎一切寄存器都挂在 `clk` 上：
```verilog
always @(posedge clk or negedge rst_n) begin
    if (!rst_n) q <= 0;     // 复位：上电/重启时给确定初值
    else        q <= d;     // 正常：每个时钟沿采样
end
```
- **时钟域**：不同时钟之间传数据要专门同步（见 UART 里的 `rx_d1/rx_d2` 两级寄存器），否则会有"亚稳态" bug。
- 复位让电路有确定起点（类比对象构造函数里初始化字段）。

## 5. 没有"动态"——一切资源编译期固定

- 没有 `malloc`/GC：寄存器、RAM、DSP 数量在综合时定死。
- 没有递归、没有运行时可变长度循环。
- 位宽要自己管：`4'd15 + 1 = 0`（4 位回绕），不像 Dart 的 `int` 自动变大。

## 6. 调试方式也变了

| 软件 | 硬件（仿真） |
|------|--------------|
| 打断点、单步 | 看**波形**（每根信号随时间的值），见 GTKWave |
| `print()` | `$display` / `$monitor` |
| 单元测试 | **testbench**（自己写激励 + 断言，本仓库每个案例都有） |
| 日志 | 波形文件 `.vcd` |

## 7. 典型新手 bug 清单（先记住，少踩坑）
1. 在 `always @(*)` 的某条分支忘了给输出赋值 → 综合出**意外锁存器**
2. 时序块里用了 `=` 或组合块里用了 `<=` → 仿真和上板行为不一致
3. 在时钟沿瞬间改 testbench 激励 → 采样到的是旧值还是新值不确定（本仓库 FSM/UART 的 README 有踩坑说明）
4. 跨时钟域直接连线 → 亚稳态、偶发错误
5. 位宽不匹配导致截断/符号扩展错误
